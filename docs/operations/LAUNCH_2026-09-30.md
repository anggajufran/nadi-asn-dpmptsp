## Arsitektur akses

Hanya container web NADI ASN terhubung jaringan proxy kantor. App/database tidak dipublikasikan ke jaringan proxy; port web privat tetap bind localhost. Nginx Proxy Manager memakai konfigurasi khusus NADI ASN dan tidak mengubah host aplikasi kantor lainnya. Gunakan kedua file Compose saat membuat ulang service web.

## Menutup akses publik sementara

```sh
cd /home/anggauser/nadi-asn
docker cp infra/domain/nadi-domain.conf npm:/data/nginx/nadi/domain.conf
docker exec npm nginx -t && docker exec npm nginx -s reload
```

Ini mengaktifkan halaman maintenance tanpa menghapus database, volume, akun atau sertifikat. Konfigurasi publik dapat dipasang kembali dari `infra/domain/nadi-domain-public.conf` setelah masalah selesai. Env sebelum rilis tersimpan privat di `.deploy/domain/app.env.before-public`; jangan memulihkan seluruh env lama tanpa meninjau kredensial pemulihan terbaru. Jangan gunakan rollback database untuk sekadar mengganti halaman maintenance.
