## Lokasi konfigurasi

Template dalam repository: `infra/domain/nadi-domain.conf`, `maintenance.html`, `renew-certificate.sh`.
Salinan pada VPS: `.deploy/domain/` (direktori privat pengelola).

Nginx Proxy Manager (`npm`) memuat konfigurasi tambahan melalui:

```text
/data/nginx/custom/http.conf
  include /data/nginx/nadi/*.conf;
/data/nginx/nadi/domain.conf
/data/nadi-public/maintenance.html
```

Bind mount host berada di `/opt/npm/data`. Pengaturan ini dikelola sebagai konfigurasi khusus, sehingga tidak muncul sebagai Proxy Host pada UI Nginx Proxy Manager. Jangan membuat Proxy Host kedua untuk domain yang sama tanpa memigrasikan konfigurasi ini terlebih dahulu.

Sertifikat menggunakan namespace Certbot terpisah di `/etc/letsencrypt/nadi-asn` dalam container `npm`, dengan bind mount host `/opt/npm/letsencrypt/nadi-asn`. Private key tidak disalin ke repository. Sertifikat lain yang dikelola Nginx Proxy Manager menggunakan namespace semula.
